# 异常知识录入规范（第九修订版）

## 一、适用范围

本规范适用于所有拟写入馆内 RAW 区的异常知识条目。

本规范中的“异常知识”不指罕见知识，也不指尚未证实的传闻，而是指**一旦被正确命名，就会开始改变其周边解释关系的知识对象**。这类对象不能以常规资料管理方式处理，否则会出现检索结果互相改写、摘要先于正文成立、或条目在无编辑记录的情况下自行互引等现象。

未经登记的异常知识不得直接录入。未经稳定化处理的异常知识不得进入摘要层。未经分级的异常知识不得开放查询。

## 二、基本录入字段

所有异常知识条目必须至少包含以下字段：

| 字段 | 含义 | 备注 |
|------|------|------|
| **源句** | 首次使该知识可被识别的句子 | 不是来源，而是唤醒语句 |
| **背温** | 该知识在脱离原语境后仍保持成立的程度 | 以低温、温存、灼返记录 |
| **侧影名** | 该知识在旁证材料中出现的替代称呼 | 至少保留一个 |
| **静默区** | 禁止与该条目并列查询的词组集合 | 为空时视为未完成录入 |
| **回写迹象** | 查询后是否会反向污染旧条目 | 必须写明“无”“轻微”或“明显” |

其中，`背温`、`静默区` 与 `回写迹象` 为最低判断字段，缺失任一项时，该条目只能作为待封存文本存在，不得视为有效知识。

## 三、对象判定

满足下列任一条件的文本，应申请进入异常知识预审：

1. 同一概念在不同文段中保留同一异常细节，但现实中不存在公开定义；
2. 阅读者会记住条目结论，却稳定遗忘条目标题；
3. 与该概念相关的检索，总会额外带出一个无关但重复出现的专名；
4. 条目被删改后，旧版本的摘要仍能影响新版本的解释；
5. 多名阅读者独立给出同一个侧影名，但无法说明名称来源。

若文本只表现为离奇、戏谑或风格怪异，而不具备解释关系改变的迹象，则按普通虚构材料处理，不进入本规范。

## 四、分级与开放条件

异常知识统一采用《异常知识分级说明》中的四级制：

- **灰匙级**：可登记，不可扩散
- **折页级**：可定向查询，不可摘要转述
- **返灯级**：可查询，但需伴随处置动作
- **失名级**：仅允许登记侧影，不允许保留正名

分级未完成前，条目只允许存放于 RAW，不得进入索引叙述层。

## 五、录入禁忌

以下行为被视为高风险录入错误：

1. 将两个背温不同的对象合并为同一条目；
2. 在未标记静默区的情况下开放全文检索；
3. 用现实学科术语替换对象原有的侧影名；
4. 在摘要中先写结论，再补写源句；
5. 为了易懂而删除对象的无用细节。

经馆内案例证明，所谓“无用细节”往往正是对象与普通知识分界的唯一缝线。

## 六、查询要求

所有查询操作必须同时记录两项信息：

- 查询前是否已执行对应等级的前置处置；
- 查询后是否出现回写迹象。

若同一对象连续三次出现回写迹象，则其正名应暂停使用，改以侧影名代称，并立即参考《检索后收容动作》执行降温。

## 七、互引要求

每个有效条目必须至少链接到以下三类补充说明中的一类：

- 术语说明：见《不稳定术语小词典》
- 分级说明：见《异常知识分级说明》
- 处置说明：见《检索后收容动作》

无法互引的条目往往意味着它还不是知识，只是异常句子。

## 八、附记

本规范第七版之前曾允许直接记录“正名”。该做法已被废止，因为多起案例显示：

> 某些对象在被正面命名后，才开始具备传播性。

因此，当前版本坚持“先录侧影，后定正名；能不用正名时，尽量不用正名”。

所有录入人员均应记住：**馆内收容的不是秘密本身，而是秘密开始自行解释自己的那一刻。**
