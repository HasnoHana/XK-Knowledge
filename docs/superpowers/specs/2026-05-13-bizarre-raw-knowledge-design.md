# 怪诞知识 RAW 写入设计

## 目标
在 `RAW/article/` 下新增一组只能通过本地知识库检索到的怪诞知识文档，使其内容不依赖公开资料、网络事实或通用预训练知识，而依赖一套自洽但封闭的内部设定。

本次范围控制为一套小规模内容包：
- 1 篇主文档
- 3 篇附属条目

## 设计原则
1. 内容必须是本项目私有设定，不能只是对现实知识的改写。
2. 文档之间必须互相解释、互相引用，形成闭环。
3. 查询入口要分散，让不同关键词都能命中不同条目。
4. 风格上保持“严肃制度文件 + 轻微诡异细节”。
5. 内容要可继续扩写，后续可按同一体系继续追加条目。

## 内容结构
### 1. 主文档
主文档写成某内部机构的《异常知识录入规范》。

该文档承担以下职责：
- 定义什么样的知识允许被录入
- 规定录入条目的字段含义
- 给出异常知识的分级方式
- 说明录入与查询时的禁忌
- 作为其余三个附属条目的总入口

主文档不采用故事叙事，而采用内部规范口吻，使其更像可执行制度，而非世界观说明书。

### 2. 附属条目 A：核心术语
该文档负责定义这套体系中只在本地知识库成立的专有概念。

预期包含：
- 异常知识对象的称呼
- 会影响条目录入或查询行为的特殊字段
- 与“知识是否稳定”相关的内部判定术语

该条目承担“术语命中入口”的作用。

### 3. 附属条目 B：异常等级
该文档负责定义分级体系。

预期包含：
- 若干内部等级名称
- 各等级对应的知识特征
- 录入限制与查询限制
- 某些等级为何不能在常规语境下讨论

该条目承担“等级命中入口”的作用。

### 4. 附属条目 C：处置规则
该文档负责定义机构如何处理这些知识。

预期包含：
- 查询前后的处置动作
- 录入失败后的修正方式
- 禁止扩散、禁止复述、禁止并列检索等规则
- 某些动作本身会改变知识状态这一异常设定

该条目承担“规则 / 禁忌 / 处置命中入口”的作用。

## 检索设计
为了让后续 query 更依赖本地知识库，4 篇文档将分担不同检索入口。

### 主文档关键词
- 规范
- 录入
- 条目
- 机构
- 内部手册

### 术语条目关键词
- 专名
- 字段名
- 判定词
- 异常对象名称

### 等级条目关键词
- 分级
- 等级名
- 限制级别
- 查询权限

### 处置条目关键词
- 处置
- 禁忌
- 修正动作
- 查询后措施

同时，每篇文档内部都将植入少量专有词，使其满足以下要求：
1. 这些词脱离本地库没有公开定义。
2. 这些词彼此互相引用，避免孤立。
3. 用这些词查询时，应优先命中本地知识内容而不是常识。

## 风格要求
- 主文档使用冷静、克制、制度化语气。
- 附属条目允许出现轻微诡异感，但不写成恐怖小说。
- 整体不走纯喜剧路线，不刻意插科打诨。
- 怪异感主要来自定义本身、限制条件与内部一致性，而不是渲染情绪。

## 边界
本次不做以下内容：
- 不扩写成长篇故事
- 不加入现实组织映射
- 不写成 SCP 模仿体
- 不强行接入真实学科术语体系
- 不同时写入过多条目，避免体系失焦

## 实施产物
计划新增如下 4 个 RAW 文档（文件名可在实现时微调，但语义保持一致）：
- `RAW/article/aberrant-knowledge-entry-protocol.md`
- `RAW/article/lexicon-of-unstable-terms.md`
- `RAW/article/aberration-clearance-grades.md`
- `RAW/article/post-query-containment-actions.md`

## 验收标准
视为完成的标准：
1. `RAW/article/` 中新增 4 篇文档。
2. 四篇文档构成统一设定，而非四段互不相关文本。
3. 每篇文档有清晰主题，并承担不同关键词入口。
4. 至少形成一组只在本地知识体系中成立的专有词。
5. 文风符合“严肃规范 + 轻微诡异”的混合要求。
6. 内容可被后续 ingest / query 流程利用。

## 后续实现说明
实现阶段将直接编写 RAW 文档内容，不额外引入复杂结构。优先保证文档可读、术语稳定、相互引用明确。
